Access Developer / Junior DBA

Full-Time · Remote · 6 Months – 1 Year Experience

Full-Time Remote 6 Mo – 1 Year Exp

Job Summary

We are looking for a Junior DBA / Microsoft Access Developer to support an ongoing Microsoft Access to SQL Server migration project. The primary focus of this role will be understanding, analyzing, documenting, and assisting in the migration of a large Microsoft Access application into SQL Server.

The ideal candidate should have strong hands-on knowledge of Microsoft Access, including Forms, Queries, Reports, Macros, VBA modules, and database relationships. The candidate should also possess basic SQL Server and DBA knowledge such as backup, restore, and SQL query understanding.

This role is best suited for someone who enjoys understanding legacy applications, analyzing workflows, and working closely with database systems.

Mandatory Skills — Microsoft Access (Primary)

Candidate must have practical experience in:

  • Microsoft Access application development
  • Understanding and analyzing existing Access databases
  • Forms, Queries, Reports, and VBA Modules
  • Writing and modifying VBA code
  • SQL queries in Access
  • Understanding table relationships and database structure
  • Debugging Access applications
  • Reviewing and documenting workflows / business logic
  • Working with linked tables and external data sources
  • Understanding complex legacy Access applications

Mandatory Skills — SQL Server (Basic Level)

Candidate should have basic working knowledge of:

  • SQL Server databases and SQL queries
  • Backup and Restore process
  • Database connectivity
  • Tables, Views, Stored Procedures (basic understanding)
  • Access to SQL Server migration concepts
  • SQL Server Management Studio (SSMS)

Roles & Responsibilities

  • Analyze existing Microsoft Access applications
  • Review Forms, Queries, Reports, Macros, and VBA code
  • Understand and document complete application workflows
  • Prepare technical documentation for existing modules
  • Assist in migration from Microsoft Access to SQL Server
  • Identify database relationships and dependencies
  • Work with SQL Server backend databases
  • Support database maintenance activities
  • Perform basic SQL Server DBA tasks
  • Coordinate with development and migration teams

Preferred Skills

  • Knowledge of Access frontend and SQL Server backend architecture
  • Experience with linked SQL tables in Access
  • Understanding of legacy system modernization
  • Basic knowledge of stored procedures and indexing
  • Good debugging and analytical skills
  • Documentation experience

Educational Qualification

  • Bachelor's degree in Computer Science, IT, or a related field
  • Relevant certifications are an added advantage

Key Traits

  • Strong analytical and logical thinking
  • Good understanding of database workflows
  • Attention to detail
  • Willingness to learn and work on legacy systems
  • Good communication and documentation skills

Nice-to-Have Skills

  • Experience in Access-to-SQL migration projects
  • Knowledge of ADO / DAO
  • Exposure to SSIS or data migration tools
  • Basic performance tuning knowledge
  • Experience with version / documentation tools
Important Note

This role is heavily focused on Microsoft Access application analysis and migration activities. Candidates with strong Microsoft Access knowledge will be preferred.
