VBA Developer

Full-Time · Fully Remote · 6 Months – 1 Year Experience

Full-Time Remote 6 Mo – 1 Year Exp

Job Summary

We are looking for a VBA Developer to support an ongoing Microsoft Access to SQL Server migration project. The primary focus of this role will be understanding, analyzing, and maintaining existing VBA modules while assisting in the conversion of a large Microsoft Access application into SQL Server.

The ideal candidate should have strong hands-on knowledge of VBA development, including Access Forms, Queries, Reports, Macros, and database relationships. Knowledge of SQL Server, Azure, or any other database system is a plus and gives candidates an added advantage in hiring.

This is a fully remote position, best suited for someone who enjoys understanding legacy applications, analyzing workflows, and working closely with database systems.

Mandatory Skills — VBA Development (Primary)

Candidate must have 6 months to 1 year of hands-on experience in:

  • VBA (Visual Basic for Applications) development
  • Understanding and analyzing existing VBA modules
  • Microsoft Access Forms, Queries, Reports, and Macros
  • Writing and modifying VBA code
  • SQL queries in Access
  • Understanding table relationships and database structure
  • Debugging VBA and Access applications
  • Reviewing and documenting workflows / business logic
  • Working with linked tables and external data sources
  • Understanding complex legacy Access applications

Good to Have — SQL Server / Azure

Knowledge of any of the following is not mandatory but gives an added advantage in hiring:

  • SQL Server databases and SQL queries
  • Azure or other cloud database systems
  • Backup and Restore process
  • Tables, Views, Stored Procedures (basic understanding)
  • Access to SQL Server migration concepts
  • SQL Server Management Studio (SSMS)

Roles & Responsibilities

  • Analyze and maintain existing VBA modules
  • Review Forms, Queries, Reports, Macros, and VBA code
  • Understand and document complete application workflows
  • Prepare technical documentation for existing modules
  • Assist in migration from Microsoft Access to SQL Server
  • Identify database relationships and dependencies
  • Support database maintenance activities where needed
  • Coordinate with development and migration teams

Preferred Skills

  • Knowledge of SQL Server, Azure, or any other database system
  • Experience with linked SQL tables in Access
  • Understanding of legacy system modernization
  • Basic knowledge of stored procedures and indexing
  • Good debugging and analytical skills
  • Documentation experience

Educational Qualification

  • Bachelor's degree in Computer Science, IT, or a related field
  • Relevant certifications are an added advantage

Key Traits

  • Strong analytical and logical thinking
  • Good understanding of database workflows
  • Attention to detail
  • Willingness to learn and work on legacy systems
  • Good communication and documentation skills

Nice-to-Have Skills

  • Experience in Access-to-SQL migration projects
  • Knowledge of ADO / DAO
  • Exposure to SSIS or data migration tools
  • Basic performance tuning knowledge
  • Experience with version / documentation tools
Important Note

This role is heavily focused on VBA development and Access-to-SQL migration activities. Candidates with strong VBA knowledge will be preferred; SQL Server or Azure knowledge is a plus, not a requirement. This is a fully remote position.
